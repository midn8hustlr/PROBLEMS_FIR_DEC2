Complete the partial Verilog RTL code in sources/fir_filter_dec2.v which implements a high-speed 16-tap FIR filter with decimation by 2.

The filter should use polyphase decomposition technique to relax the critical path based on the specification in docs/Specification.md.
The RTL code should be synthesizable.
The reset is active-low and asynchronous.

For internally dividing the clock, use a clock divider followed by an ICG (Integrated Clock Gating) Cell for power savings.
